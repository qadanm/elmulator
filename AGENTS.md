# Elmulator contribution rules

Elmulator is independent MIT testing infrastructure. Preserve Swift/Python byte-for-byte parity. Establish expected fixture outcomes from cited external references or deliberately specified synthetic facts before decoder changes. Never change bytes to make a consumer pass. No real VINs, Bluetooth identifiers, private app code, or credentials in commits. No public push/release without explicit user authorization.

Read `~/.agents/skills/building-native-ios27-apps/SKILL.md` (expand `~` for the current developer) for native Swift work; apply its scope/evidence rules to Python without imposing UI APIs. Use installed SDK declarations over cached API claims. Baseline commands: `swift test`, `PYTHONPATH=python/src python -m pytest python/tests`, `PYTHONPATH=python/src python conformance/run_conformance.py --swift-bin .build/debug/elmulator-tcp`. Set DEVELOPER_DIR to the intended Xcode when multiple versions are installed. Work in isolated ticket branches and report exact tests and untested radio behavior.
